# 洗浄工程 薬液管理基準 (架空のサンプル文書)

文書番号: STD-CLN-011 / 改訂 3 / 制定部署: 洗浄技術グループ
※ このリポジトリのデモ用に作った架空の文書です。

## 1. 対象
SC-1 (アンモニア過酸化水素水) 洗浄槽を持つ洗浄装置 CLN-01、CLN-02 (SC-1200)。

## 2. 薬液温度
- 標準 65.0 ℃、管理幅 ±1.0 ℃。
- 66.5 ℃ を超えると過酸化水素の分解が速まり、槽内の金属 (特に Fe) がウェーハ表面に再付着しやすくなる。表面 Fe 濃度が上がるおそれがあるため、66.5 ℃ 超の状態で処理したロットは金属汚染の抜き取り検査を増やす。
- 温調器を交換・修理した後は、1 週間、薬液温度を 1 時間ごとに記録して安定を確認する。

## 3. メガソニック
- 出力 1200 W、管理幅 ±50 W。出力低下はパーティクル除去率の低下につながる。

## 4. 金属汚染の管理値
- 表面 Fe 濃度: 1 × 10^10 atoms/cm² 未満 (判定上限は 3 × 10^9 atoms/cm² を工程管理値とする)。
